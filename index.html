GUIDO — Genomic Unified Intelligence for Disease Oncology

Transcriptomics cancer biomarker modeling and literature linking prototype connecting ranked genomic candidates to PubMed abstracts (Groq LLaMA 3).

AXEL

AXEL — Automated Document Extraction & Search

Document ingestion, OCR, and semantic vector embedding pipeline for multi-format text retrieval.

Problem: Extracting and searching information across heterogeneous files (PDFs, scans, DOCX) is slow when limited to exact string matching.
Approach: Combined Tesseract OCR and pdfplumber for text extraction, generated 384-dimensional dense embeddings with sentence-transformers, and injected metadata tags back into file properties.
Result: Enables natural language semantic search and metadata tag injection across multi-format documents (PDF, DOCX, and images).

Python · sentence-transformers · Tesseract OCR · pdfplumber · ChromaDB
